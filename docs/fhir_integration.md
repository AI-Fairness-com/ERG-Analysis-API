# HL7 FHIR R4 Integration for ERG Analysis API

## Overview

This document defines the HL7 FHIR R4 profile for full-field ERG data generated by the ERG Analysis API. FHIR (Fast Healthcare Interoperability Resources) is the international standard for health data exchange, mandated by an increasing number of national health information frameworks, including NHS England's API standards and the EU European Health Data Space regulation.

**Source:** Appendix B of the ERG manuscript

---

## Observation Resource Template

Each ERG parameter from a single recording is represented as an HL7 FHIR R4 Observation resource. The Observation uses LOINC codes where available and a custom extension for ISCEV-specific parameters that do not yet have LOINC codes.

### Base Observation Structure

```json
{
  "resourceType": "Observation",
  "id": "[UUID generated at report time]",
  "status": "final",
  "category": [{
    "coding": [{
      "system": "http://terminology.hl7.org/CodeSystem/observation-category",
      "code": "procedure",
      "display": "Procedure"
    }]
  }],
  "code": {
    "coding": [{
      "system": "http://loinc.org",
      "code": "70943-7",
      "display": "Electroretinogram"
    }],
    "text": "Full-field ERG, ISCEV 2022 Standard"
  },
  "subject": {
    "reference": "Patient/[patient_id]",
    "display": "[de-identified patient reference]"
  },
  "effectiveDateTime": "[recording_date]T[recording_time]Z",
  "performer": [{ "reference": "Practitioner/[recording_centre_id]" }],
  "device": {
    "reference": "Device/[device_manufacturer]",
    "display": "[device_manufacturer]"
  },
  "component": [
    // See Component Mapping section below
  ],
  "extension": [
    {
      "url": "https://erg-api.org/fhir/StructureDefinition/iscev-protocol",
      "valueCode": "[protocol]"
    },
    {
      "url": "https://erg-api.org/fhir/StructureDefinition/electrode-type",
      "valueCode": "[electrode_type]"
    },
    {
      "url": "https://erg-api.org/fhir/StructureDefinition/traffic-light",
      "valueCode": "[GREEN|AMBER|RED]"
    },
    {
      "url": "https://erg-api.org/fhir/StructureDefinition/api-version",
      "valueString": "[api_version]"
    }
  ]
}
