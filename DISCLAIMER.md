# Legal and Ethical Disclaimer

## Important Distinction: Technical ERG Analysis vs Clinical Diagnosis

The ERG Analysis API is a **technical signal processing and machine learning tool** that analyzes full-field electroretinogram (ERG) recordings. It provides statistical comparisons against normative reference data, Traffic Light classifications (GREEN/AMBER/RED), and calibrated probability estimates for retinal disease classes.

**The ERG Analysis API is NOT a clinical diagnosis tool.**

Source: Blueprint Section 2.4, p. 5

> *"This ERG Traffic Signal is generated solely from electroretinographic signal analysis using validated machine learning techniques trained on clinician-confirmed cases. It represents ERG findings only and must be interpreted in the context of the patient's full clinical picture. The Traffic Signal does not constitute a clinical diagnosis. The final clinical decision remains the sole responsibility of the supervising clinician. A Green ERG signal does not exclude significant ocular or systemic pathology."*

---

## What the ERG Analysis API Does

- Processes ISCEV 2022-compliant full-field ERG recordings
- Applies standardized filtering (0.3–300 Hz Butterworth bandpass)
- Computes Z-scores against age-stratified normative reference data (Baker et al., 2025, N=407)
- Generates STFT spectrograms for deep learning classification
- Produces calibrated probability estimates for seven retinal conditions
- Provides three-level SHAP explainability (feature-level, spectrogram-level, plain-language)
- Generates four-layer clinical reports (Traffic Light, Clinical Summary, Specialist Report, Audit)

---

## What the ERG Analysis API Does NOT Do

- **Does not** provide a clinical diagnosis
- **Does not** replace the clinical judgment of a qualified healthcare professional
- **Does not** guarantee that a GREEN result excludes all retinal pathology
- **Does not** provide legal or regulatory compliance advice
- **Does not** certify a patient as "healthy" or "disease-free"
- **Does not** validate itself for pediatric patients (under 18 years)
- **Does not** support pattern ERG, multifocal ERG, or electrooculography in Phase 1

## Traffic Light Interpretation

Source: Chapter 1 §1.7; Blueprint Section 2.3

| Color | Z-Score Range | Clinical Meaning |
|-------|---------------|------------------|
| 🟢 **GREEN** | \|Z\| ≤ 2.0 | Within normal limits. No immediate action required. |
| 🟡 **AMBER** | 2.0 < \|Z\| ≤ 3.0 | Borderline abnormality. Specialist review recommended. |
| 🔴 **RED** | \|Z\| > 3.0 | Significant abnormality. Urgent review required. |

**Important caveat:** The ±2.0 SD Green boundary was chosen to prioritize sensitivity for early disease detection. At this threshold, approximately 5% of healthy subjects will receive an Amber classification. This false-positive rate is documented in the Model Card (Chapter 17) and is considered acceptable for a screening triage tool.

## Age-Stratified Reference Ranges

Source: Baker et al. (2025); Blueprint Section 2.3

The normative reference data are stratified by three age groups:

| Age Group | Range |
|-----------|-------|
| ≤35 years | Young adults |
| 36–59 years | Middle-aged adults |
| ≥60 years | Older adults |

Z-scores are computed against the age-matched normative stratum. Using an age-mismatched reference range will produce systematically incorrect Traffic Light assignments.

## Intended Use and Scope

**Intended use:** Clinical decision support for adult full-field ERG recordings (ages 18–80 years) in ophthalmology and clinical electrophysiology settings.

**Intended users:** Retinal electrophysiologists, specialist ophthalmologists, optometrists working in extended-scope electrophysiology clinics, and clinical research teams.

**Out of scope (Phase 1):**
- Pediatric patients (under 18 years)
- Pattern ERG (pERG)
- Multifocal ERG (mfERG)
- Electrooculography (EOG)
- Autonomous diagnosis without clinician review
- Non-ISCEV-compliant recordings
- Disease classes outside the seven trained categories

## Professional Responsibility

Users of the ERG Analysis API are responsible for:

1. Ensuring that ERG recordings are ISCEV 2022-compliant
2. Verifying that electrode type and recording device are correctly specified
3. Interpreting Traffic Light results within the full clinical context
4. Seeking specialist review for all AMBER and RED results
5. Understanding that a GREEN result does not exclude retinal pathology
6. Documenting clinical decisions and their rationale

## Data Privacy (GDPR Compliance)

Source: Blueprint Section 4.9

- **Patient ID:** Anonymized reference only. No name, date of birth, or national identifier is stored or transmitted.
- **Data minimization (GDPR Article 5):** Raw signal files are permanently deleted after report generation.
- **Right to erasure (GDPR Article 17):** The delete function on every stored report permanently removes all associated data.
- **Data retention:** 7 years (UK clinical records standard, user-configurable).
- **Security:** HTTPS enforced (cloud); local AES-256 encryption (offline); no third-party analytics; no tracking cookies; full audit log.
